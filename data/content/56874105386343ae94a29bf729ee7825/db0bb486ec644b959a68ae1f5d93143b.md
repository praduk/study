A **function** $f:A\to B$ is a relation $f\subseteq A\times B$ such that for every $a\in A$ there is exactly one $b\in B$ with $afb$. Write that value as $f(a)$. The set $A$ is the domain and $B$ is the specified codomain.

For $X\subseteq A$ and $Y\subseteq B$,

$$
f[X]=\{f(x):x\in X\},\qquad
f^{-1}[Y]=\{x\in A:f(x)\in Y\}.
$$

The function is **injective** if $f(a)=f(a')$ implies $a=a'$, **surjective** if every $b\in B$ equals $f(a)$ for some $a\in A$, and **bijective** if both. Restriction, $f\mathbin{\upharpoonright}X$, is the graph of $f$ restricted to $X$. Composition is relational composition and is associative.

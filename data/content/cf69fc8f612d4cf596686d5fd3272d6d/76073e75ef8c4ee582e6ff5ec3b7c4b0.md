Assume Choice. Apply it to the set of fibers $\{\{i\}\times A_i:i\in I\}$. A choice from each fiber has the form $\langle i,a_i\rangle$. Sending $i$ to $a_i$ defines an element of the product.

Conversely, let $\mathcal A$ be a set of nonempty sets. Regard it as an indexed family with index set $\mathcal A$ and fiber $A$ at index $A$. A member $f$ of
$\prod_{A\in\mathcal A}A$ has domain $\mathcal A$ and satisfies $f(A)\in A$. Thus $f$ is a choice function for $\mathcal A$.

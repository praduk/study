A set $\Gamma$ is **satisfiable** if some valuation satisfies every member of $\Gamma$; otherwise it is **unsatisfiable**. A formula $A$ is:

- a **tautology** or **logically valid** if every valuation satisfies it;
- a **contradiction** if no valuation satisfies it;
- **contingent** if some valuation satisfies it and some valuation does not.

These cases are exhaustive and mutually exclusive. Satisfiability is a property of a formula or set having at least one model; validity is a property of a formula holding under every valuation.

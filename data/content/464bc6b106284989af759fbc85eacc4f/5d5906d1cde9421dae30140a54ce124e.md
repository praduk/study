Fix a formula $\varphi(x,p_1,\ldots,p_n)$ and set parameters $p_1,\ldots,p_n$. The notation

$$
\{x:\varphi(x,p_1,\ldots,p_n)\}
$$

denotes the **definable class** of all sets satisfying the formula. It is shorthand in the metatheory, not automatically a set and not a new object over which ZF quantifies.

A definable class is a **set-class** if some set has exactly its members. Otherwise it is a **proper class**. For example, after ordinals are defined, $\mathrm{Ord}=\{x:x\text{ is an ordinal}\}$ is a proper class.

Class notation may be used in an abbreviation such as $F:A\to\mathrm{Ord}$, provided the actual assertion can be expanded into a first-order formula. It is invalid to infer that an arbitrary definable class is a set.

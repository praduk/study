In ZF, **set** is the single primitive kind of object over which the first-order variables range. Membership $x\in A$ is the sole nonlogical primitive relation. There is no further definition inside ZF that reduces “set” to a more basic object.

A set is determined extensionally: once the Axiom of Extensionality is assumed, $A=B$ exactly when $A$ and $B$ have the same members. A formula such as $\{x\in B:\varphi(x)\}$ denotes a set only because an axiom or theorem supplies its existence; braces are not an unrestricted set-producing operation.

This entry is an orientation to the formal primitive, not a claim that every collection is a set. Definable collections too large to be sets are treated as proper classes in the metatheory.

Well-order all sentences as $(θ_α)_{α<κ}$. Put $T_0=T$. At a successor stage, let $T_{α+1}=T_α∪\{θ_α\}$ if this is consistent, and otherwise let $T_{α+1}=T_α∪\{¬θ_α\}$. The second choice must be consistent: if both extensions were inconsistent, implication introduction would give $T_α⊢¬θ_α$ and $T_α⊢¬¬θ_α$; classical double-negation elimination would give $T_α⊢θ_α$, contradicting consistency. At a limit ordinal $λ$, put $T_λ=⋃_{α<λ}T_α$. If this union derived $⊥$, finite character would place all used assumptions in one earlier $T_α$, again a contradiction.

Let $T^*=⋃_{α<κ}T_α$. It is consistent by the same finite-character argument. Every sentence is decided at its stage, so $T^*$ is negation-complete. If $T^*⊢φ$ but $φ∉T^*$, then $¬φ∈T^*$, contradicting consistency; hence it is deductively closed. Any proper extension adds a sentence whose negation is already present and is inconsistent, so $T^*$ is maximal consistent.

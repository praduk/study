Using only NAND,

$$\neg A\equiv A\uparrow A,$$

$$A\land B\equiv(A\uparrow B)\uparrow(A\uparrow B).$$

Thus NAND can express $\neg$ and $\land$; functional completeness follows from @math:prop:normal-forms:th:standard-complete-bases.

Using only NOR,

$$\neg A\equiv A\downarrow A,$$

$$A\lor B\equiv(A\downarrow B)\downarrow(A\downarrow B).$$

Thus NOR can express $\neg$ and $\lor$, so it too is functionally complete. Each identity follows directly from the defining truth function, including all four possible input pairs for the binary identities.

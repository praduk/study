Suppose an original structure satisfies the prenex sentence. Read the quantifier prefix as a finite semantic game. For each existential quantifier and every tuple of values of the preceding universal variables, the semantics provides a nonempty set of witnesses compatible with suitable later choices. Working in ordinary set theory with the axiom of choice, choose one witness uniformly for every such tuple, proceeding through the finite prefix. Interpret the corresponding fresh Skolem function by this choice function. Induction along the prefix then shows that the expanded structure satisfies the universal Skolemized sentence. Finiteness of the prefix alone would not justify a uniform choice over a possibly infinite set of tuples; the choice principle is the metatheoretic step.

Conversely, suppose an expansion satisfies the Skolemized sentence. Given values for the preceding universal variables, use the value of the relevant Skolem term as the witness for each deleted existential quantifier. Induction along the original prefix shows that its reduct satisfies the original sentence. Thus models correspond only through existence of suitable expansions and reducts; arbitrary expansions need not work.

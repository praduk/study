Let $f:\{0,1\}^n\to\{0,1\}$ with $n\geq1$. Form the disjunction of the minterms belonging to assignments $a$ with $f(a)=1$. By the canonical-DNF argument, the resulting formula represents $f$ and uses only $\neg,\land,\lor$. If there are no such assignments, use $p_1\land\neg p_1$. Thus the first set is functionally complete.

Every occurrence of $A\lor B$ can be replaced by $\neg(\neg A\land\neg B)$, yielding an equivalent formula that uses only $\neg$ and $\land$. Therefore $\{\neg,\land\}$ is functionally complete. Dually, replace $A\land B$ by $\neg(\neg A\lor\neg B)$ to obtain a formula using only $\neg$ and $\lor$. Hence the third set is functionally complete.

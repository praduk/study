The naive comprehension principle would assert that for every condition $\varphi(x)$ there is a set $A=\{x:\varphi(x)\}$. Taking $\varphi(x)$ to be $x\notin x$ would give a set

$$
R=\{x:x\notin x\}.
$$

Then $R\in R$ if and only if $R\notin R$, a contradiction. This is Russell's paradox.

ZF therefore does not permit an arbitrary condition to collect all satisfying objects into a set. Separation only carves a subset from an already available set, while Replacement collects the values of a functional definition over an already available set. The restriction is structural, not cosmetic.

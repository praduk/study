A separation of $X$ is a decomposition $X=U\cup V$ into disjoint nonempty open sets. The space is connected when it has no separation. It is path connected when every two points can be joined by a continuous map $[0,1]\to X$.

A connected component is a maximal nonempty connected subset. A path component is an equivalence class for being joined by a path. The empty space is connected and path connected by these conventions but has no components.

If $a<b$ are rational, choose irrational $c$ between them. The sets $\Q\cap(-\infty,c)$ and $\Q\cap(c,\infty)$ are disjoint clopen subsets separating $a$ from $b$. A connected subset therefore contains at most one point. Each singleton is connected, so components are singletons. A path image is connected, so every path is constant; path components are also singletons. No singleton is open because every usual neighborhood of a rational contains other rationals.

If an open neighborhood $U$ of $x$ misses $A$, then the closed set $X\setminus U$ contains $A$ and excludes $x$, so $x\notin\closure A$. Conversely, if $x$ is outside the intersection of all closed sets containing $A$, at least one such closed set $F$ excludes $x$. Then $X\setminus F$ is an open neighborhood missing $A$. This proves the equivalence. Failure of the neighborhood condition is exactly membership in $\Int(X\setminus A)$, giving the formula.

The first argument is invalid. Let $v(p)=0$, $v(q)=0$, and $v(r)=1$. Then $p\to q$ and $q\to r$ are both true, while $r\to p$ is false. This is a countervaluation because it makes every premise true and the conclusion false.

The replacement conclusion is valid. If a valuation satisfies both premises and $p$ is true, $p\to q$ forces $q$ to be true and $q\to r$ then forces $r$ to be true. Thus $p\to r$ is true. If $p$ is false, $p\to r$ is true automatically. Hence $p\to q,q\to r\models p\to r$.

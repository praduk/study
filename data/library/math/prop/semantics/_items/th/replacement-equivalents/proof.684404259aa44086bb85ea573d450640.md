Induct on the construction of the context. If the context is only the hole, the result is the hypothesis $A\equiv B$. If the hole lies under negation, the induction hypothesis says the two filled child formulas have equal values under every valuation, and applying the negation truth function preserves equality. If the hole lies in one child of a binary connective, the induction hypothesis makes that child's values equal; the unchanged other child has the same value in both filled contexts. Applying the binary connective's truth function therefore gives equal values for the two whole formulas. These are all possible context constructions, so the claim holds for every context.

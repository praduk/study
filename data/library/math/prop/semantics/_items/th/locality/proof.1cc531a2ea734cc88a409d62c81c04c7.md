Use structural induction on $A$. If $A$ is an atom, the claim is the agreement hypothesis; for $\true$ and $\false$, both evaluations are fixed. If $A=\neg B$, then $\operatorname{At}(B)=\operatorname{At}(A)$, so the induction hypothesis gives equal values for $B$, and applying the negation truth function gives equal values for $A$. If $A=B\circ C$, agreement on $\operatorname{At}(A)=\operatorname{At}(B)\cup\operatorname{At}(C)$ gives agreement on each child's atoms. The induction hypotheses give equal values for both children under $v$ and $w$; applying the same binary truth function for $\circ$ gives equal values for $A$.

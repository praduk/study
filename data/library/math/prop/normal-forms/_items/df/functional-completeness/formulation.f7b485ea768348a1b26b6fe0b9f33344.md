An $n$-ary **Boolean function** is a function $f:\{0,1\}^n\to\{0,1\}$. A formula $A(p_1,\ldots,p_n)$ **represents** $f$ if its value under every assignment to those atoms is $f$ of that assignment.

A set of connectives is **functionally complete** if every Boolean function of positive finite arity can be represented by a formula using only atoms and connectives from that set. Constants can be represented when needed by $p\lor\neg p$ and $p\land\neg p$.

A @[smooth map]math:diffgeo:manifolds:df:smooth-map is an immersion if each differential is injective and a submersion if each differential is surjective. A smooth embedding is an immersion that is also a @[homeomorphism]math:pst:spaces:df:continuity onto its image with the @[subspace topology]math:pst:constructions:df:subspace.

An embedded $k$-submanifold is a subset admitting ambient charts in which it is the coordinate slice $\R^k\times\{0\}$. An injective immersion alone is not sufficient to assert an embedded image; the induced topology must also be checked.

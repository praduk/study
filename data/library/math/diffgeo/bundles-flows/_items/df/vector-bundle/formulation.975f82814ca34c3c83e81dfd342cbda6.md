A rank-$r$ smooth real vector bundle is a smooth map $\pi:E\to M$ whose fibers are $r$-dimensional vector spaces, with local diffeomorphisms $\pi^{-1}(U)\isoto U\times\R^r$ commuting with projection and linear on each fiber. A section is a smooth map $s:M\to E$ with $\pi s=\id_M$.

A local frame is a list of $r$ sections forming a basis in each fiber. A bundle is trivial when it admits one global trivialization. Local triviality does not imply global triviality.

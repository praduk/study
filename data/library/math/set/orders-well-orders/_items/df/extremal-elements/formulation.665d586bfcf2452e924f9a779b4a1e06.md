In a partially ordered set $(P,\le)$:

- $m$ is **minimal** if no $x<m$ exists;
- $M$ is **maximal** if no $x>M$ exists;
- $0$ is **least** if $0\le x$ for every $x\in P$;
- $1$ is **greatest** if $x\le1$ for every $x\in P$.

Least and greatest elements, when they exist, are unique. Minimal or maximal elements need not be unique and need not be comparable.

A **chain** is a subset whose elements are pairwise comparable. An **antichain** is a subset whose distinct elements are pairwise incomparable. An upper bound of $C\subseteq P$ need not lie in $C$; a maximal element of $P$ is not necessarily a greatest element.

Assume Choice and the chain-upper-bound hypothesis. Suppose, for contradiction, that $P$ has no maximal element. Choice supplies an upper bound for every chain and, for every $p\in P$, an element strictly above $p$. Use transfinite recursion through $h(P)$: at stage $\alpha$, the earlier chosen elements form a chain; choose an upper bound $u$ of that chain and then choose $p_\alpha>u$. Thus $p_\beta<p_\alpha$ whenever $\beta<\alpha$, so $\alpha\mapsto p_\alpha$ injects $h(P)$ into $P$, contradicting Hartogs' theorem. Therefore a maximal element exists.

Conversely, assume Zorn's Lemma. Given a set $\mathcal A$ of nonempty sets, let $P$ be the set of partial choice functions: functions $p$ with $\operatorname{dom}(p)\subseteq\mathcal A$ and $p(A)\in A$ for every $A$ in the domain. Order $P$ by extension. The union of any chain of compatible partial functions is again a partial choice function and is an upper bound. Zorn gives a maximal $p$. If some $A\in\mathcal A$ were absent from its domain, choose one $a\in A$ and extend $p$ by $\langle A,a\rangle$, contradicting maximality. Hence $p$ is a choice function on all of $\mathcal A$, so Choice holds.

First choose any set $A$; first-order structures have nonempty domains. Apply Separation to $A$ with the formula $x\ne x$. This produces

$$
E=\{x\in A:x\ne x\},
$$

and no set belongs to $E$. If both $E$ and $F$ have no members, then for every $x$,
$x\in E\leftrightarrow x\in F$ (both sides are false). Extensionality gives $E=F$. Thus the memberless set exists and is unique.

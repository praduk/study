The singleton map $a\mapsto\{a\}$ injects $A$ into $\mathcal{P}(A)$.

Now let $f:A\to\mathcal{P}(A)$ be any function and form the diagonal set

$$
D=\{a\in A:a\notin f(a)\}.
$$

If $f$ were surjective, some $d\in A$ would satisfy $f(d)=D$. Then

$$
d\in D\leftrightarrow d\notin f(d)\leftrightarrow d\notin D,
$$

a contradiction. Thus no such $f$ is surjective. Since an injection exists in the other direction, the strict inequality follows.

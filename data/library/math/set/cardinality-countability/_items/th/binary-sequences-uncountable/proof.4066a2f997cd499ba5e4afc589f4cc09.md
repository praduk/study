Map each subset $S\subseteq\omega$ to its characteristic function $\chi_S$, where $\chi_S(n)=1$ exactly when $n\in S$. This map is injective because distinct subsets differ at some $n$, and it is surjective because any $b:\omega\to\{0,1\}$ is the characteristic function of $\{n:b(n)=1\}$. Hence $2^\omega\approx\mathcal{P}(\omega)$.

If $2^\omega$ were countable, then $\mathcal{P}(\omega)$ would inject into $\omega$. Cantor--Schröder--Bernstein, together with the singleton injection $\omega\to\mathcal{P}(\omega)$, would give $\omega\approx\mathcal{P}(\omega)$, contradicting Cantor's theorem. Therefore $2^\omega$ is uncountable.

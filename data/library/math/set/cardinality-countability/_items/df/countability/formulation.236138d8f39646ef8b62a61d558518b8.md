A set $A$ is **finite** if $A\approx n$ for some $n\in\omega$. It is **countably infinite** if $A\approx\omega$. In this course, **countable** means *at most countable*: there is an injection $A\to\omega$. A set is **uncountable** if it is not countable.

A set is **Dedekind-infinite** if it is equinumerous with a proper subset of itself. In ZF every Dedekind-infinite set is infinite, but the converse is not provable in ZF. Under the Axiom of Choice, every infinite set contains a countably infinite subset and is therefore Dedekind-infinite.

When a source uses “countable” to mean countably infinite, translate the statement explicitly rather than silently changing conventions.

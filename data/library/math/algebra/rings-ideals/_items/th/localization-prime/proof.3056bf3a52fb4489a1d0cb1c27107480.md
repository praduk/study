The displayed set is an ideal. It is proper: if $r/s=1$ with $r\in P$, the @[equivalence relation]math:set:relations-functions:df:equivalence-relation gives $t(r-s)=0$ for some $t\notin P$, hence $ts=tr\in P$, contradicting primality. If a fraction lies outside this ideal, its numerator is outside $P$, so $r/s$ has inverse $s/r$. Thus all elements outside the ideal are units. No proper ideal can contain a unit, so every proper ideal is contained in $PR_P$, making it the unique @[maximal ideal]math:algebra:rings-ideals:df:prime-maximal.

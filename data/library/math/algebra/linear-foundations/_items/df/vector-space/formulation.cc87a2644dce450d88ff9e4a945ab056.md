Let $K$ be a field. A vector space over $K$ is an @[abelian group]math:algebra:groups-actions:df:groups-homomorphisms $(V,+)$ with scalar multiplication $K\times V\to V$ satisfying $a(v+w)=av+aw$, $(a+b)v=av+bv$, $(ab)v=a(bv)$, and $1v=v$ for all $a,b\in K$ and $v,w\in V$. Thus it is a @math:algebra:modules-structure:df:module over a field.

A linear subspace is a subset containing zero and closed under addition and scalar multiplication. A map $T:V\to W$ between spaces over the same field is linear when $T(av+bw)=aT(v)+bT(w)$. Its kernel is $\{v:T(v)=0\}$ and its image is $\{T(v):v\in V\}$; both are subspaces. A linear endomorphism maps a space to itself, and a linear isomorphism is a bijective linear map.

The zero vector space is allowed. An affine subspace is a translate $v_0+U$ of a linear subspace; it need not contain zero. For example $\{(x,y):x+y=1\}$ is affine but is not a linear subspace of $\R^2$.

A morphism $m:A\to B$ is monic if $mu=mv$ implies $u=v$ for all parallel $u,v:X\to A$. A morphism $e:A\to B$ is epic if $ue=ve$ implies $u=v$ for all parallel $u,v:B\to Y$.

A split monomorphism has a left inverse; a split epimorphism has a right inverse. Multiplying a cancellation equation by the relevant inverse shows every split mono is monic and every split epi is epic. An isomorphism has both properties. The converse that a map both monic and epic is an isomorphism is not true in every category.

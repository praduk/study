An initial object $0$ has exactly one morphism $0\to X$ for every object $X$. A terminal object $1$ has exactly one morphism $X\to1$. A zero object is both initial and terminal; it determines a zero morphism $X\to0\to Y$ for every pair.

In $\Set$, the empty set is initial and each singleton is terminal, but there is no zero object. In $\Grp$ and $\Vect_k$, the trivial group and zero vector space are zero objects. In the category of unital commutative rings, $\Z$ is initial and the zero ring is terminal under the convention that the zero ring is included.

The opposite category $\mathcal C^{\mathrm{op}}$ has the same objects as $\mathcal C$, with $\Hom_{\mathcal C^{\mathrm{op}}}(A,B)=\Hom_{\mathcal C}(B,A)$. Composition is reversed. It satisfies the category axioms because associativity and identity equations remain valid when arrows reverse.

A statement in category theory has a dual obtained by reversing all arrows and the order of compositions. For example, a statement about initial objects dualizes to one about terminal objects. Dualizing twice recovers the original category and statement. This is a formal operation on the entire assertion, including hypotheses.

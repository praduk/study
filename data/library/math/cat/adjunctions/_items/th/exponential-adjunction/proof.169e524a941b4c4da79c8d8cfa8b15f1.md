For $f:X\times B\to Y$, define $\widehat f(x)$ to be the function $b\mapsto f(x,b)$. Conversely send $g:X\to Y^B$ to $(x,b)\mapsto g(x)(b)$. Evaluating at all pairs $(x,b)$ verifies that these are inverse. Precomposing a function into $X$ and postcomposing a function out of $Y$ commute with both formulas, proving naturality. The counit is evaluation $Y^B\times B\to Y$. The formulas remain valid for $B=\varnothing$, when $Y^B$ is a singleton and $X\times B$ is empty.

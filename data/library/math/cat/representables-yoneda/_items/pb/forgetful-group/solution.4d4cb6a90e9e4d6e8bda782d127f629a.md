For each group $G$, evaluate a homomorphism $f:\Z\to G$ at $1$. It is determined by $g=f(1)$, because $f(n)=g^n$ for all integers, including zero and negative integers. Conversely every $g\in G$ defines this homomorphism. Evaluation is therefore a bijection $\Hom_{\Grp}(\Z,G)\cong U(G)$. For a homomorphism $h:G\to H$, evaluation of $hf$ gives $h(f(1))$, so the bijections are natural. The universal element is $1\in U(\Z)$, not the additive identity $0$.

A functor $F:\mathcal C\to\mathcal D$ is faithful if each map $\Hom_{\mathcal C}(A,B)\to\Hom_{\mathcal D}(FA,FB)$ is injective, full if each is surjective, and fully faithful if each is bijective. It is essentially surjective if each object of $\mathcal D$ is isomorphic to some $FA$.

The forgetful functor $\Grp\to\Set$ is faithful but not full: a function between underlying groups need not preserve multiplication. A full subcategory retains every ambient morphism between its chosen objects. Essential surjectivity is weaker than literal surjectivity on objects.

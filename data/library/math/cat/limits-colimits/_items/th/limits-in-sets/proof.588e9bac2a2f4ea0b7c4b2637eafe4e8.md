Each family in $L$ satisfies the cone equalities, so the projections form a cone. Given another cone $p_j:X\to D(j)$, define $u(x)=(p_j(x))_j$. The cone identities put this tuple in $L$, and its projections are exactly the $p_j$. Any map with these projections must give the same tuple at each $x$, proving uniqueness. When $J$ is empty, the product is the singleton containing the empty tuple, so the formula gives the @[terminal object]math:cat:categories-morphisms:df:initial-terminal as required. No choice of an element in each $D(j)$ is asserted; the limit can be empty.

Truncating after coordinate $N$ gives a finite-rank operator $T_N$ with $\norm{T-T_N}=1/(N+1)$. A norm limit of @[compact operators]math:analysis:spectral-theory:df:spectrum-compact is compact: for a bounded sequence, repeatedly extract subsequences for each $T_N$, take a diagonal subsequence, and use the operator-norm approximation to show its $T$-images are Cauchy. Completeness supplies the image limit. The diagonal coefficients are real, so the inner-product formula shows $T=T^*$.

Each $1/n$ has eigenvector $e_n$. The operator is injective, so zero is not an eigenvalue, but it is not onto: $(1/n)$ lies in $\ell^2$ and its only formal preimage is $(1,1,\ldots)$, which does not. Finally, if $\lambda$ lies outside the displayed closed set, $\inf_n|1/n-\lambda|>0$. Coordinatewise division by $1/n-\lambda$ defines a bounded inverse of $T-\lambda I$. Hence no other spectral values occur.

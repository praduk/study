If $f(x_0)>0$, continuity gives a ball compactly contained in $\Omega$ on which $f\ge\epsilon>0$. Choose a nonnegative nonzero smooth bump supported in that ball. Such a bump is supplied explicitly by a translate and rescaling of $\exp(-1/(1-|x|^2))$ for $|x|<1$, extended by zero. Then $\int f\phi\ge\epsilon\int\phi>0$, a contradiction. If $f(x_0)<0$, apply the same argument to $-f$. Independent test components give the vector conclusion. The hypothesis is an equality of @math:analysis:distributions-sobolev:df:distribution pairings; positivity and a localized test recover the pointwise assertion because $f$ is continuous.

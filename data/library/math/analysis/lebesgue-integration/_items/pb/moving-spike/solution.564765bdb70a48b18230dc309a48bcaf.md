For each $x>0$, eventually $1/n<x$, so $f_n(x)=0$ and the pointwise limit is zero. Yet $\int_0^1 f_n(x)\,dx=n(1/n)=1$. If a single integrable $g$ dominated all $f_n$ almost everywhere, dominated convergence would force these integrals to tend to zero, a contradiction. The same computation gives $\norm{f_n}_p^p=n^{p-1}$ for $1\le p<\infty$: it stays one for $p=1$ and diverges for $p>1$.

A single measurable null set contains all exceptional sets, since there are only countably many. Off it, $|f|\le g$ and $|f_n-f|\le2g$. The measurable functions may be set to zero on that null set without changing their integrals. Fatou applied to $2g-|f_n-f|\ge0$ gives

$$
2\int g\le\liminf_n\left(2\int g-\int|f_n-f|\right).
$$

Since $\int g<\infty$, this implies $\limsup_n\int|f_n-f|\le0$. Finally $|\int(f_n-f)|\le\int|f_n-f|$ proves convergence of the integrals.

An outer measure is a map $\mu^*:\mathcal P(X)\to[0,\infty]$ satisfying $\mu^*(\varnothing)=0$, monotonicity, and countable subadditivity. A set $A\subseteq X$ is Carathéodory measurable if for every $E\subseteq X$,

$$
\mu^*(E)=\mu^*(E\cap A)+\mu^*(E\setminus A).
$$

Subadditivity always supplies the inequality from left to right; measurability requires the reverse inequality as well. The test ranges over all subsets $E$, not merely the measurable ones.

Set $\nu_a(A)=\int_A2x\,dx$ and $\nu_s(A)=3\,1_A(1/2)$. If $m(A)=0$, the integral is zero, so $\nu_a\ll m$. The second measure is concentrated on $\{1/2\}$, a Lebesgue null set, so $\nu_s\perp m$. These give the unique decomposition; $d\nu_a/dm=2x$ almost everywhere. The entire $\nu$ has no density with respect to $m$, because $m(\{1/2\})=0$ but $\nu(\{1/2\})=3$. Any proposed integral density would assign zero to that singleton.

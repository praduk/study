Set $M_i=M/m_i$. Choose $u_i$ with $M_i u_i\equiv1\pmod{m_i}$ using Bézout. Then $x=\sum_i a_iM_iu_i$ has every required residue: all but one summand vanish modulo each $m_i$. If $x,y$ have the same residues, each $m_i$ divides $x-y$. Unique prime factorization and pairwise coprimality imply $M\mid x-y$. The reduction map preserves addition and multiplication directly, so the existence and uniqueness prove the isomorphism.

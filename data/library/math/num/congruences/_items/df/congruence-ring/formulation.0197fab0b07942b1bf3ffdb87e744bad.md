For a positive integer $m$, $a\equiv b\pmod m$ means $m\mid a-b$. This is an @[equivalence relation]math:set:relations-functions:df:equivalence-relation; its classes form $\Z/m\Z$ with $[a]+[b]=[a+b]$ and $[a][b]=[ab]$. These operations are well-defined because replacing an input by a multiple-of-$m$ perturbation changes either result by a multiple of $m$. A unit is a class with a multiplicative inverse. Modulo $1$ there is one class, with $0=1$.

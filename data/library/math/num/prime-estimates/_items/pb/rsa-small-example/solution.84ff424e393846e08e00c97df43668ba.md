We need $3d\equiv1\pmod{40}$, so $d=27$. Encryption gives $7^3=343\equiv13\pmod{55}$. For decryption use $13^2\equiv4$, $13^4\equiv16$, $13^8\equiv36$, $13^{16}\equiv31$. Thus $13^{27}\equiv31\cdot36\cdot4\cdot13\equiv7\pmod{55}$. For $m=5$, the message is not a unit modulo $55$, but the correctness proof works separately modulo $5$ (both sides zero) and modulo $11$ (Fermat), then combines them by CRT.

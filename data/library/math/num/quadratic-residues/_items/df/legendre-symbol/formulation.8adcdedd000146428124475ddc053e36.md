For an odd prime $p$, an integer $a$ not divisible by $p$ is a quadratic residue modulo $p$ if $x^2\equiv a\pmod p$ for some $x$; otherwise it is a quadratic nonresidue. The Legendre symbol $\left(\frac ap\right)$ is $0$ if $p\mid a$, $1$ for a nonzero quadratic residue, and $-1$ for a nonresidue. There are $(p-1)/2$ nonzero squares: $x^2=y^2$ implies $x=\pm y$ in the field, and each nonzero square has exactly these two roots.

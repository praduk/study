For a continuous matrix function $A:I\to\R^{n\times n}$, a fundamental matrix of $x'=A(t)x$ is a matrix $\Phi(t)$ whose columns are a basis of solutions; equivalently $\Phi'=A\Phi$ and $\det\Phi(t_0)\ne0$ at one point. Uniqueness ensures $\Phi(t)$ is invertible throughout $I$: if $\Phi(t)c=0$ at any point, the solution $\Phi(\cdot)c$ with zero initial state is identically zero, forcing $c=0$. Every homogeneous solution is $x(t)=\Phi(t)c$ for a unique constant vector $c$.

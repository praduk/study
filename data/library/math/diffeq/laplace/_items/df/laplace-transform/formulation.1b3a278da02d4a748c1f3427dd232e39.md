For a piecewise continuous function $f:[0,\infty)\to\R$, its Laplace transform is $F(s)=\mathcal L\{f\}(s)=\int_0^\infty e^{-st}f(t)\,dt$ when absolutely convergent. Exponential order means $|f(t)|\le Me^{at}$ for all sufficiently large $t$, for some $M,a$. Then the transform exists for real $s>a$. Direct integration gives $\mathcal L\{1\}=1/s$ for $s>0$ and $\mathcal L\{e^{at}\}=1/(s-a)$ for $s>a$. The transform is linear wherever the separate absolute integrals exist.

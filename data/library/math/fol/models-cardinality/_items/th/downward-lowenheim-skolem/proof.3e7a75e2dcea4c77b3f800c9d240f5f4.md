Let $κ=\max(|A|,|L|,ℵ_0)$. For each formula $∃xφ(x,\bar y)$, choose in $𝔐$ a witness function $F_φ$ on parameter tuples whenever a witness exists. Begin with $A_0$ containing $A$, all interpretations of constants, and one element. Given $A_n$, let $A_{n+1}$ contain $A_n$, the values of all language function symbols on tuples from $A_n$, and every chosen witness $F_φ(\bar a)$ for formulas and tuples $\bar a$ from $A_n$ for which $𝔐⊨∃xφ(x,\bar a)$.

There are at most $κ$ formulas, finite tuples, function applications, and witness choices at each stage, so $|A_n|≤κ$ by induction. Let $N=⋃_{n<ω}A_n$ and give it the induced substructure. Then $|N|≤κ$. If $𝔐⊨∃xφ(x,\bar a)$ with $\bar a∈N$, all parameters lie in some $A_n$, so the selected witness lies in $A_{n+1}⊆N$. The Tarski–Vaught test yields $𝔑≺𝔐$. The final statement follows by applying this to a model with $A=∅$.

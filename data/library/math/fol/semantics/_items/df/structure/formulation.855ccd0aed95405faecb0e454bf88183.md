An $L$-structure $𝔐$ consists of a nonempty domain $M$ together with: an element $c^𝔐∈M$ for each constant $c$; a total function $f^𝔐:M^n→M$ for each $n$-ary function symbol $f$; and a relation $R^𝔐⊆M^n$ for each $n$-ary relation symbol $R$. Logical equality is interpreted as actual identity on $M$.

An expansion interprets additional symbols without changing the old domain or old interpretations. A reduct forgets interpretations. Neither operation by itself asserts elementary equivalence.

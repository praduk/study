Start with a prenex sentence. Process existential quantifiers from left to right. Replace an existential variable $y$ by a new Skolem function $f(x_1,…,x_k)$ whose arguments are exactly the universally quantified variables preceding that existential, then delete $∃y$. If none precede it, use a new Skolem constant. The remaining universal quantifiers may be left explicit or implicitly universally close the matrix.

The result is a sentence in an expanded signature. Different existential quantifiers receive distinct fresh symbols. Omitting a genuine dependency can change satisfiability; adding irrelevant earlier universal arguments is safe but nonminimal.

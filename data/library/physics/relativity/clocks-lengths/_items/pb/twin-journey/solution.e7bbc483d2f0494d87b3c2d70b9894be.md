The stationary clock measures $T=2L/v$. Each traveling leg takes laboratory time $L/v$ and proper time $L/(v\gamma)$, so $\tau=2L/(v\gamma)$ and $T-\tau=(2L/v)(1-\sqrt{1-v^2/c^2})>0$. These are lengths of two specified worldlines between the same endpoints, not contradictory applications of time dilation to one inertial pair. The traveler changes inertial frames at turnaround; the stationary clock does not. A smooth short turnaround approaches this piecewise timelike calculation when its additional durations are negligible. There is no universal rule that aging difference is a function only of peak acceleration.

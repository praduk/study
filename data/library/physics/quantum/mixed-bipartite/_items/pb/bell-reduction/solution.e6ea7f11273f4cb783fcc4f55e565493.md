The projector expands into four terms $|00\rangle\langle00|$, $|00\rangle\langle11|$, $|11\rangle\langle00|$, $|11\rangle\langle11|$, each with factor $1/2$. Tracing either factor removes the off-diagonal terms, so $\rho_A=\rho_B=I/2$ and each local purity is $1/2$. Both basis components have equal $z$ outcomes, so $\langle\sigma_z\otimes\sigma_z\rangle=1$. If a normalized product $a\otimes b$ represented this state, its partial trace would be $|a\rangle\langle a|$ with purity one, contradicting the calculation. The pair is therefore entangled although either local $z$ outcome alone is unbiased.

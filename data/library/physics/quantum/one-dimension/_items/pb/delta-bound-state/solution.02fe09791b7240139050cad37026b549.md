For $E=-\hbar^2\kappa^2/(2m)<0$, square integrability forces $\psi=Ae^{\kappa x}$ for $x<0$ and $\psi=Be^{-\kappa x}$ for $x>0$. Continuity gives $A=B$. The derivative jump is $-2\kappa A$, so a nonzero state requires $\kappa=m\lambda/\hbar^2$. Normalization gives $1=|A|^2/\kappa$, hence up to phase $\psi=\sqrt\kappa e^{-\kappa|x|}$ and $E=-m\lambda^2/(2\hbar^2)$. There is exactly one allowed positive $\kappa$, so no other negative-energy state satisfies the specified conditions. $\lambda$ has units J m.

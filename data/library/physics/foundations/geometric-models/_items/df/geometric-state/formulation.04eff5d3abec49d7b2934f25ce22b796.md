For a finite-dimensional smooth model, a state space is a @math:diffgeo:manifolds:df:smooth-manifold $S$, a real observable is a @[smooth map]math:diffgeo:manifolds:df:smooth-map $f:S\to\mathbb R$, and autonomous deterministic evolution is a vector field $X$ with local flow $\Phi_t$. Along a trajectory, $\frac{d}{dt}f(\Phi_t(s))=df(X)$. A change of coordinates changes the components of $X$, not the trajectory in $S$.

A physical symmetry is a diffeomorphism $\Psi:S\to S$ preserving the model's structures and evolution: $\Psi_*X=X$. Gauge-related descriptions instead represent the same physical state; a quotient is a smooth state manifold only when its regularity has been justified. Singular quotients occur, so a coordinate-free notation by itself does not establish well-posedness.

The choice of extra structure carries physical content: @math:diffgeo:geometric-structures:df:symplectic for Hamiltonian dynamics, @math:diffgeo:geometric-structures:df:pseudo-metric for spacetime, and @math:diffgeo:geometric-structures:df:contact for a thermodynamic phase space. Field models require spaces of sections and appropriate functional analysis; the finite-dimensional definition is not a theorem about those infinite-dimensional spaces.

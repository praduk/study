A passive transformation changes coordinates while holding the geometric object fixed. An active transformation changes the object relative to a fixed frame. For a scalar field, an active spatial rotation $R$ acts by $f_R(x)=f(R^{-1}x)$.

Covariance means an equation is expressed consistently in the chosen descriptions. Covariance by itself does not establish a physical symmetry: background structures and boundary data may select preferred directions or frames. Always state what is transformed and what is held fixed.

A monomial $\ell^a g^b$ has dimension $L^{a+b}T^{-2b}$. Matching time gives $b=-1/2$ and $a=1/2$. Equivalently, the only independent time scale from these dimensional inputs is $\sqrt{\ell/g}$, so $P=\sqrt{\ell/g}\,f(\theta_0)$ for an undetermined dimensionless function $f$. No dimensional argument determines $f$. The small-amplitude dynamical model later yields $f(0)=2\pi$ as a limit, not as a dimensional necessity.

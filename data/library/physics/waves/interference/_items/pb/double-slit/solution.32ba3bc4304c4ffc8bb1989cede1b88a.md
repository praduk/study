The path difference is approximately $dX/z$, so phase changes by $2\pi$ when $X$ increases by $\lambda z/d=0.0020\,\mathrm m=2.0\,\mathrm{mm}$. Full coherence gives cross-term magnitude $2\sqrt{I_1I_2}=4I_0$. Thus $I_{\max}=9I_0$, $I_{\min}=I_0$, and visibility $8I_0/(10I_0)=0.8$. Destructive interference is incomplete because the field amplitudes differ. The spacing uses both far-field path linearization and small observation angle; finite slit width also supplies a diffraction envelope.

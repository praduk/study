For a nonempty set $X$ and a ring $A$, the functions $X\to A$ form a ring with operations $(f+g)(t)=f(t)+g(t)$ and $(fg)(t)=f(t)g(t)$ for each $t\in X$. Its zero is the constant zero function. If $A$ has an identity, the multiplicative identity is the constant function with value $1_A$. Each @[ring axiom]mt4-ring can be checked by evaluating both sides at an arbitrary $t$ and using that axiom in $A$.

The orbit is $Hx$. Every element has the form $hx$, so the map is surjective. If $h_1x=h_2x$, right cancellation gives $h_1=h_2$, proving injectivity.
By the orbit equivalence relation, these orbits partition $G$. Each has $|H|$ elements. If there are $t$ orbits, $|G|=t|H|$, hence $|H|\mid|G|$.
These orbits $Hx$ are **right cosets**, even though the action is by left multiplication. No normality is needed.

**Technique:** count a partition into equally sized pieces using explicit bijections.

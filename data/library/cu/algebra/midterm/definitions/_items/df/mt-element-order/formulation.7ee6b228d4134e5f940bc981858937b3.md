For $g\in G$, let $g^0=1$, let $g^m$ be a product of $m$ copies for $m>0$, and set $g^{-m}=(g^{-1})^m$.
The **order** $|g|$ is the least positive $n$ with $g^n=1$, if one exists; otherwise $|g|=\infty$. It equals $|\langle g\rangle|$, where $\langle g\rangle=\{g^m:m\in\Z\}$.
The identity has order one; an **involution** has order exactly two. The condition $g^2=1$ permits either order one or order two.
Example: $\overline4\in(\Z/12\Z,+)$ has order three.

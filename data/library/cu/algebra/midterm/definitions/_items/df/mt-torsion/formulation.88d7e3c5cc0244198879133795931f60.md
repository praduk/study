An element is a **torsion element** if it has finite order. For an abelian group $G$, the set $T(G)=\{g:|g|<\infty\}$ is its **torsion subgroup**.
Example: in the additive group $\Z\times(\Z/n\Z)$, it is $\{0\}\times(\Z/n\Z)$. In a nonabelian infinite group the finite-order elements may fail closure, so calling their set a subgroup requires proof. In a finite group every element is torsion.

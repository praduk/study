For $H\le G$ and $g\in G$, the **left coset** is $gH=\{gh:h\in H\}$ and the **right coset** is $Hg=\{hg:h\in H\}$.
The **index** $[G:H]$ is the number of left cosets. A set of **coset representatives** contains exactly one element from each coset. Right and left cosets have the same number, via $gH\mapsto Hg^{-1}$.
Left multiplication by $H$ has orbits $Hg$, the right cosets. Right multiplication by $H$ has orbits $gH$, the left cosets.
For finite $G$, $[G:H]=|G|/|H|$. The set $G/H$ of left cosets is not automatically a quotient group: that requires normality.

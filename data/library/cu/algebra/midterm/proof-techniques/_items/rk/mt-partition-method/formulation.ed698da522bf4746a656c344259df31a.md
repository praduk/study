**Use when:** a divisibility theorem comes from an action.

Prove reflexivity using $1$, symmetry using an inverse, and transitivity using a product. This supplies a partition into orbits. Next construct an explicit bijection from a known set to each orbit; prove both injectivity and surjectivity. Only then multiply “number of pieces” by “size of each piece.”

In 1.7.19 the map $h\mapsto hx$ is a bijection $H\to Hx$ by cancellation and the definition of the orbit. Thus all pieces have size $|H|$ and $|G|$ is a multiple of $|H|$.

**Assigned uses:** 1.7.18, 19; 2.3.25 indirectly through Lagrange.

**Common failure:** arbitrary orbits of an arbitrary action need not all have the same size. Prove the particular bijection here; do not assume it from the word “orbit.”

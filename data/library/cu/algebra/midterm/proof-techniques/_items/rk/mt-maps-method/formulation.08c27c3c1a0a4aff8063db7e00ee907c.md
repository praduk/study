**Use when:** proving groups are isomorphic, translating presentations, or preserving a property.

Specify a candidate map, then check well-definedness, multiplication, injectivity, and surjectivity. For a map defined on generators, verify all defining relations so it extends to a homomorphism. Prove the images generate for surjectivity. If domain and codomain have the same finite cardinality, a surjection is automatically a bijection. Alternatively construct an inverse map and check both composites.

To disprove isomorphism, find a preserved property that differs: cardinality, being abelian, or number of elements of a given order. To prove a statement about the codomain, surjectivity lets you write arbitrary elements as images; injectivity lets you reflect equality back to the domain.

**Assigned uses:** 1.2.7; 1.6.2, 3, 20; 2.2.12(c,e); 2.4.12.

**Common failure:** relations plus a matching-looking list do not prove injectivity. State the counting or inverse-map argument explicitly.

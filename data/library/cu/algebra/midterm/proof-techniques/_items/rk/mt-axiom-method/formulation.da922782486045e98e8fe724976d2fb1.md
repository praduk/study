**Use when:** a set with an operation is claimed to be a group, subgroup, or action.

1. State the domain, codomain, and operation precisely.
2. Prove the formula stays in the claimed set and is independent of representation.
3. If it is a subset of a known group with the inherited operation, use the subgroup criterion rather than reprove associativity.
4. If defining a new group operation, check associativity, identity, and inverses explicitly.
5. For an action, verify both $1a=a$ and $(gh)a=g(ha)$; check fixed-$g$ bijectivity if using a permutation representation.

**Assigned uses:** 1.1.9, 28; 1.4.11(a,b); 1.6.20; 1.7.8, 14, 15; 2.1.6, 9; 2.2.12(b).

**Common failure:** closure alone does not imply subgroup for an infinite subset; $\Z_{>0}$ under addition is a counterexample. A one-sided set containment does not establish equality for infinite sets.

**Use when:** proving identities for arbitrary products or integer powers.

Establish the two-factor identity, state the induction hypothesis, then show the $n+1$ step. For an integer exponent claim, treat positive, zero, and negative exponents. Associativity changes parentheses; it does not change factor order.

Basic templates: $(ab)^{-1}=b^{-1}a^{-1}$; $(ab)^n=a^nb^n$ only when $a,b$ commute; $s r^i=r^{-i}s$ in a dihedral group. To apply a hypothesis holding for all $x$, try $x=ab$ as well as $x=a,b$.

**Assigned uses:** 1.1.15, 24, 25; 1.4.11(e); 1.7.14, 15; 2.4.3.

**Proof checkpoint:** explicitly name the hypothesis that permits each swap of adjacent factors. For a statement about every element of a generated group, extend from generators to arbitrary finite words.

Write $H=\{1,t\}$ with $t\ne1$. Always $C_G(H)\subseteq N_G(H)$. If $g$ normalizes $H$, conjugation permutes its two elements and fixes $1$, so it must fix $t$: $gtg^{-1}=t$. Hence $g$ centralizes $H$ and equality follows.
If the normalizer is all of $G$, every $g\in G$ commutes with $t$, so $t\in Z(G)$ and $H\le Z(G)$.

**Technique:** exploit a bijection on a two-element set that already fixes one element.

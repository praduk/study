Let $P$ be a finite $p$-group and write $P/\Phi(P)\cong\F_p^r$. Elements $x_1,\ldots,x_s$ form an inclusion-minimal generating set of $P$ exactly when their cosets form a basis of $P/\Phi(P)$.

Every minimal generating set therefore has $r$ elements, and no generating set has fewer. In particular, if $P/\Phi(P)$ is cyclic, then $P$ is cyclic; the same follows if $P/P'$ is cyclic.

This is the basis theorem, distinct from the factorization @mt3-frattini-argument and the definition @mt3-frattini-subgroup.

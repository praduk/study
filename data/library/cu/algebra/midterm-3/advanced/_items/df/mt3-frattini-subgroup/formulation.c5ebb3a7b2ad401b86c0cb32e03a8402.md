The **Frattini subgroup** $\Phi(G)$ is the intersection of all maximal proper subgroups of $G$. If no such subgroup exists, set $\Phi(G)=G$.

An element $x\in G$ is a **nongenerator** if $\langle H,x\rangle<G$ for every proper subgroup $H<G$. The equality between nongenerators and $\Phi(G)$ is the theorem @mt3-frattini-nongenerators.

For use in @mt3-frattini-quotient, the notation $P^p=\langle x^p:x\in P\rangle$ denotes the subgroup generated by all $p$th powers; for a nonabelian group the set of powers alone need not be a subgroup.

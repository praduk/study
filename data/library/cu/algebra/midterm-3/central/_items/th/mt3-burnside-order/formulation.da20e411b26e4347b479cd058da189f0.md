If a finite group has order $p^a q^b$ for primes $p,q$ and integers $a,b\ge0$, then it is solvable.

**Proof status:** this is a deep theorem, not a consequence of elementary Sylow counting alone. Dummit–Foote states it in §6.1, Theorem 11(1), and proves it later using character theory. No short substitute proof is claimed here. Use it only when the problem permits such a theorem; the homework's requested elementary arguments remain separate.

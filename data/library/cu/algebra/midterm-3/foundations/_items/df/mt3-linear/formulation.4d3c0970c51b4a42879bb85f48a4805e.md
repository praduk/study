For a prime $p$, $\F_p=\Z/p\Z$ is the field of residues. A **vector space** over $\F_p$ is an abelian group written additively, with scalar multiplication satisfying the usual distributive, associative, and identity axioms.

A set **spans** if every vector is a finite linear combination of its elements; it is **linearly independent** if a linear combination is zero only when all coefficients are zero. A **basis** is an independent spanning set. Its cardinality is the **dimension**. A finite-dimensional space of dimension $r$ has $p^r$ vectors, because basis coordinates are unique.

A **linear map** preserves addition and scalar multiplication; a **linear functional** has target $\F_p$. A **line** is a one-dimensional subspace, and a **hyperplane** has codimension $1$. See @mt3-lines-hyperplanes for their counting theorem.

For a linear transformation $T$, its **fixed subspace** is $\{v:T(v)=v\}$. A subspace $W$ is **invariant** if $T(W)\subseteq W$. An invariant subspace need not be fixed pointwise.

**Definitions and results used:** @[Group actions and fixed points]mt3-group-action; @[Orbit–stabilizer]mt3-actions.

The orbits partition $X$. Each orbit has size dividing $|P|$, so its size is a power of $p$. An orbit has size $1$ exactly when its point is fixed by all of $P$. All other orbit sizes are divisible by $p$, proving the congruence. If no point were fixed, the congruence would make $|X|$ divisible by $p$.

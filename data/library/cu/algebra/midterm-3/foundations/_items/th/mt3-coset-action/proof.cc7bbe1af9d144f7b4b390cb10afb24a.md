**Definitions and results used:** @[Group actions]mt3-group-action.

Define $g\cdot(xH)=(gx)H$. Changing the representative $x$ does not change the resulting coset, and multiplication in $G$ verifies the action laws. The element $yx^{-1}$ sends $xH$ to $yH$, proving transitivity.

An element $g$ fixes every coset exactly when $gxH=xH$ for every $x$, or equivalently $x^{-1}gx\in H$ for every $x$. This is precisely membership in the displayed intersection. A trivial action has only singleton orbits, so it cannot be transitive on more than one coset.

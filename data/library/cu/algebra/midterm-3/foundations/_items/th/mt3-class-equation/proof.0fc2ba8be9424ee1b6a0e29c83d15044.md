**Definitions and results used:** @[Conjugation action]mt3-group-action; @[Orbit–stabilizer]mt3-actions; @[The center]mt3-center.

Conjugacy classes partition $G$. A class is a singleton exactly when its element commutes with every element of $G$, so these classes account for $|Z(G)|$ elements. The stabilizer of $x_i$ under conjugation is $C_G(x_i)$, so its class has size $[G:C_G(x_i)]$. Add the class sizes.

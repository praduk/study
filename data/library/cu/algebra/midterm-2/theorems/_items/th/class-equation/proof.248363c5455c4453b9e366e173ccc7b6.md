Conjugation defines an action $g\cdot x=gxg^{-1}$. Its stabilizer at $x$ consists exactly of elements commuting with $x$, namely $C_G(x)$. Orbit–stabilizer gives the class size. An element has singleton class precisely when it commutes with every element, so precisely when it lies in $Z(G)$. Partitioning $G$ into singleton central classes and the remaining classes gives the displayed equation.

For $|G|=p^a$, every noncentral centralizer is proper, so each corresponding index is a power of $p$ greater than $1$ and hence divisible by $p$. Reducing the class equation modulo $p$ gives $|Z(G)|\equiv0\pmod p$. The center contains the identity and thus is nonempty. Its positive order is a multiple of $p$, so at least $p$, proving it nontrivial.

For $|G|=p^2$, the center has order $p$ or $p^2$ by Lagrange. In the latter case $G$ is abelian. In the former case $G/Z(G)$ has order $p$ and is cyclic, so the central-quotient argument from Exercise 3.1.36 again makes $G$ abelian. Consequently the center is actually all of $G$.

**Technique:** noncentral orbits have sizes divisible by $p$, so singleton orbits account for the residue.

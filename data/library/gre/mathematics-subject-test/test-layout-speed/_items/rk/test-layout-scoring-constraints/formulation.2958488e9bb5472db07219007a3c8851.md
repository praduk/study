# Layout

- The GRE Mathematics Subject Test is computer-delivered.
- ETS describes approximately 66 multiple-choice questions drawn from undergraduate mathematics. The current official practice test presents five choices for each question and asks for the one best answer.
- Testing time is 170 minutes, or 2 hours 50 minutes.
- There are no separately timed sections. The test is one continuously timed pool of questions.

Using 66 questions as the planning count,

$$
\frac{170\text{ minutes}}{66\text{ questions}}
=2.5757\ldots\text{ minutes per question}
=154.55\ldots\text{ seconds per question}.
$$

Thus the average planning pace is about **2 minutes 35 seconds per question**. Because ETS says the question count is approximate, treat this as a pacing guide rather than a guaranteed per-question allowance.

# Navigation

While time remains, the computer interface allows you to:

- skip a question;
- mark a question for review;
- view a complete list showing answered and marked questions;
- return to earlier questions; and
- change an answer.

ETS warns that repeatedly consulting the review screen itself consumes testing time.

# Scoring consequences

- Every question has equal value.
- The raw result is the total number of questions answered correctly.
- An incorrect answer and an unanswered question both add zero correct answers. ETS subtracts nothing for an incorrect answer, so there is no guessing penalty.
- ETS converts the total correct score to an equated total scaled score so scores from different editions are comparable.
- The reported total score scale is 200 through 990 in 10-point increments, although the attainable range for a particular Subject Test may occupy only part of that scale.
- ETS reports one total score for Mathematics; it lists content-area percent-correct subscores only for Physics and Psychology.

The practical consequence is important: enter an answer for every question before time expires. A difficult question is not worth more than an easy one.

# Test-day constraints

- There is no scheduled break.
- At a test center, leaving your seat does not stop the clock. At-home testing does not permit an unscheduled break.
- The Subject Tests do not provide an on-screen calculator.
- A personal calculator is prohibited unless ETS has approved it as an accommodation.
- At a test center, staff provide scratch paper. Used paper must be returned before receiving more, and all scratch paper remains at the center.
- At home, ordinary paper is prohibited. ETS permits either one small desktop whiteboard with an erasable marker or one sheet of paper inside a transparent sheet protector with an erasable marker. The notes must be erased in view of the proctor at the end.

Practice without a calculator and with the note-taking surface you expect to use. Always recheck the current [ETS strategies page](https://www.ets.org/gre/test-takers/subject-tests/prepare/strategies-tips.html) and [GRE Information Bulletin](https://www.ets.org/content/dam/ets-org/pdfs/gre/gre-info-bulletin.pdf), because policies can change.

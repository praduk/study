# Status of this recommendation

ETS advises test takers to work rapidly without becoming careless, answer confident questions first, return to questions requiring more thought, leave the hardest questions until last, and answer every question. The schedule below is an independently derived implementation of that advice. **ETS does not prescribe these time limits, and no single split is proven optimal for every test taker.** Calibrate it with timed practice.

# A concrete three-pass plan

## Pass 1: coverage and secure points — minutes 0 through 100

Aim to encounter all approximately 66 questions by the 100-minute mark. That is about 91 seconds per encountered question on this pass, but it is a decision pace rather than a rigid solving limit: very short questions create time for longer ones.

- Answer immediately when the method is clear and the work is short.
- If no productive route appears after roughly 60 to 90 seconds, enter the best provisional answer, mark the question, and move on.
- Also move on when a valid method would require long, error-prone algebra and another approach is not yet visible.
- Put the question number beside any scratch work so a return visit starts from useful information rather than from zero.

Useful checkpoint: encounter roughly question 33 by minute 50 and question 66 by minute 100. Adjust for the actual number of questions shown by the test.

## Pass 2: highest-return marked questions — minutes 100 through 155

Use the marked-question list to revisit problems where additional time is most likely to produce a correct answer.

- Start with questions for which you recognized a theorem, setup, or promising reduction but needed more time.
- Prefer a three-minute problem with a clear path over an unfamiliar problem with no visible entry point; all questions have equal value.
- Use the answer choices as information: eliminate impossible signs, sizes, dimensions, parity, or domains; substitute choices when that is shorter than solving forward.
- Test universal claims with simple or boundary cases before attempting a general proof.
- Preserve exact forms when possible. Avoid decimal approximation and full symbolic expansion unless they help distinguish choices.
- Stop a second attempt when it again becomes an open-ended time sink.

## Pass 3: completion and targeted checks — minutes 155 through 170

- Use the review list to confirm that every question has an answer.
- Resolve remaining short marked questions and make a best guess on every unresolved item.
- Check only identifiable high-risk details: a reversed inequality, lost minus sign, excluded endpoint, domain restriction, multiplicity, or answering a nearby question instead of the one asked.
- Change an answer when you can state a mathematical reason, not merely because the first choice feels uncomfortable.

If practice shows that Pass 1 is skipping many questions you could solve reliably, move 5 or 10 minutes from Pass 2 into Pass 1. If you repeatedly fail to see the whole test, shorten the first-pass cutoff. Keep a final completion buffer of about 10 to 15 minutes unless your practice data supports a different choice.

# Speed techniques worth training

- Identify the requested quantity before calculating.
- Classify the problem quickly: direct recall, short computation, conceptual elimination, or extended derivation.
- Memorize core definitions and standard results well enough to recognize when they apply; speed comes more safely from recognition than from rushed algebra.
- Look for invariants, symmetry, monotonicity, rank-nullity, sign, parity, bounds, and special cases before computing extensively.
- For multiple-choice questions, compare the structure of the choices before committing to a long derivation.
- Write only enough scratch work to preserve the setup, critical transformations, and error checks.
- Train exact symbolic and mental arithmetic because no calculator is available.

# Practice protocol

1. Take the official ETS practice test under a single 170-minute clock, with no calculator, no planned break, and the same kind of scratch surface you expect on test day.
2. For every missed or slow item, record the cause: missing knowledge, slow recognition, poor setup, algebra or arithmetic error, misreading, or failure to leave a time sink.
3. Repair the cause with short topic drills, then use mixed timed sets so choosing the method becomes part of the practice.
4. Allocate study volume roughly in line with the 50/25/25 content weights, while still training precalculus fluency and weak areas. The weights are estimates, not a license to omit a named topic.
5. Repeat a full-length simulation and adjust the pass boundaries from your own accuracy-versus-time data.

The goal is not raw speed. It is the greatest reliable number of correct answers within 170 minutes.

For nonempty $A\subseteq\mathbb R$, a real number $s$ is $\sup A$ if and only if $s$ is an upper bound and, for every $\epsilon>0$, some $a\in A$ satisfies

$$
s-\epsilon<a\le s.
$$

**Memory cue (added).** A ceiling is least exactly when the set gets arbitrarily close from below.

**Answer.** Closed, not open, not compact.

**Pattern cue.** Analyze local neighborhoods, complement, and boundedness separately.

**Fast route.** Every noninteger has a small interval avoiding integers, so the complement is open. No integer has an interval contained in $\Z$, so it is not open. Unboundedness rules out compactness.

**Trap.** Discreteness as a subspace does not mean openness in the ambient real line.

For a nonempty set $A\subseteq\R$ bounded above, $s=\sup A$ iff $s$ is an upper bound and every $\varepsilon>0$ admits $a\in A$ with $s-\varepsilon<a\le s$. Completeness of $\R$ ensures this supremum exists. A supremum need not belong to $A$; it is a maximum exactly when it does.

Differentiability implies continuity, but the converse fails, for example at zero for $|x|$. Derivatives need not be continuous. The derivative of a real function differentiable on an interval nevertheless has the intermediate value property (Darboux's theorem), so it cannot jump directly between two values while omitting the values between them.

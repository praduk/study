A bounded real function on $[a,b]$ is Riemann integrable iff its discontinuity set has Lebesgue measure zero. In particular, continuous and monotone functions are Riemann integrable. Changing finitely many values preserves integrability and the integral; changing infinitely many values can do either. This criterion requires boundedness on the finite interval.

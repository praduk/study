Conditioning measures how sensitive the exact answer is to small input changes. Numerical stability concerns how a chosen algorithm handles rounding or input errors. An ill-conditioned problem can amplify even a backward-stable algorithm's small backward error. For a differentiable scalar map $f$ with $x\ne0,f(x)\ne0$, the local relative condition number is $|xf'(x)/f(x)|$.

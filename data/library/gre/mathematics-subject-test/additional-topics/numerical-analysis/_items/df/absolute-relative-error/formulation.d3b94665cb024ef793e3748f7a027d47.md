For exact value $x$ and approximation $\widehat x$, absolute error is $|\widehat x-x|$. When $x\ne0$, relative error is $|\widehat x-x|/|x|$. Relative error is undefined at exact zero and can be large even when absolute error is small. A stated tolerance must specify which kind of error it bounds.

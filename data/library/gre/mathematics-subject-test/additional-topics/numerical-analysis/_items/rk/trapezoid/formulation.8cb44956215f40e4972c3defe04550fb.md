On one panel $[a,b]$, $T=(b-a)[f(a)+f(b)]/2$. It integrates affine functions exactly. For a convex function it overestimates the integral because the chord lies above the graph. Composite trapezoidal quadrature uses this rule on successive subintervals; under a bounded second derivative on a fixed interval its global error is $O(h^2)$.

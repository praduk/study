An equivalence relation is reflexive, symmetric, and transitive. Its equivalence classes partition the underlying set; conversely a partition defines equivalence by membership in the same block. A finite class of size $k$ contributes $k^2$ ordered pairs to the relation, including all diagonal pairs.

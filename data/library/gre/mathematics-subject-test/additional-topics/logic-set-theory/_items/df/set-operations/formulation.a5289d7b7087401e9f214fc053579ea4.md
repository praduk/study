For sets in a fixed universe, $A\setminus B=A\cap B^c$, and $A\triangle B=(A\setminus B)\cup(B\setminus A)$. De Morgan's laws give $(\bigcup_iA_i)^c=\bigcap_iA_i^c$ and $(\bigcap_iA_i)^c=\bigcup_iA_i^c$. A Cartesian product contains ordered pairs; a power set contains subsets. $A\in B$ and $A\subseteq B$ assert different things. Prove set equality by testing membership in both directions.

A map $f:A\to B$ is injective iff $f(x)=f(y)$ forces $x=y$, surjective iff every $b\in B$ has a preimage, and bijective iff both. If $|A|=m,|B|=n>0$, there are $n^m$ functions and $n!/(n-m)!$ injections when $m\le n$ (zero otherwise). Equal finite domain and codomain sizes make injectivity equivalent to surjectivity; infinite sets do not.

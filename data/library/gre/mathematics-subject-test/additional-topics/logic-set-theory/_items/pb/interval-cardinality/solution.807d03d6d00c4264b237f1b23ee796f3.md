**Answer.** Inclusion injects $(0,1)$ into $[0,1]$; $x\mapsto(x+1)/3$ injects $[0,1]$ into $(0,1)$; apply Cantor–Bernstein.

**Pattern cue.** Mutual injections avoid constructing a complicated bijection.

**Fast route.** The affine image is $[1/3,2/3]\subset(0,1)$ and the map is injective. The reverse inclusion is also injective, so the theorem applies.

**Trap.** A proper subset of an infinite set may have the same cardinality.

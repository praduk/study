**Answer.** Use the contrapositive: an odd integer has odd square.

**Pattern cue.** Rewrite oddness as $n=2k+1$.

**Fast route.** Then $n^2=4k^2+4k+1=2(2k^2+2k)+1$, which is odd. This proves the contrapositive and hence the implication.

**Trap.** Checking a few odd squares does not prove the assertion for every integer.

There is no surjection $A\to\mathcal P(A)$: for a proposed map $f$, the set $D=\{a\in A:a\notin f(a)\}$ cannot equal any $f(a)$. The singleton map injects $A$ into $\mathcal P(A)$, so the power set has strictly larger cardinality. Cantor–Bernstein says that injections both ways between two sets imply a bijection.

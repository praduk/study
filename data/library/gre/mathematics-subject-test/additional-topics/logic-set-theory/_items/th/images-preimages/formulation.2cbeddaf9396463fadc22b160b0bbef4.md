Preimages preserve unions, intersections, and complements. Images preserve unions, but only $f(A\cap B)\subseteq f(A)\cap f(B)$ is automatic; equality holds for every $A,B$ if $f$ is injective. Different inputs may have equal images, so test that obstruction before asserting image identities.

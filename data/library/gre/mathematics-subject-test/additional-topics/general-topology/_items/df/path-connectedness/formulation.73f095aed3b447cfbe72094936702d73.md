A space $X$ is path connected iff for every $x,y\in X$ there is a continuous map $\gamma:[0,1]\to X$ with $\gamma(0)=x,\gamma(1)=y$. Convex subsets of $\R^n$ are path connected via straight segments. A path need not be a straight segment, and a path-connected set need not be convex.

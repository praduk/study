**Answer.** $12\pi$ and $24\pi$.

**Pattern cue.** Use height for volume and slant height for lateral area.

**Fast route.** $V=\pi\cdot9\cdot4/3=12\pi$. Slant height is five, so total area is $\pi\cdot3\cdot5+\pi\cdot9=24\pi$.

**Trap.** Using perpendicular height in the lateral-area formula is incorrect.

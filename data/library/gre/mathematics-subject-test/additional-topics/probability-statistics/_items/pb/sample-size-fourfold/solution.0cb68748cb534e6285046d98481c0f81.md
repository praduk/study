**Answer.** Four.

**Pattern cue.** Standard error scales with the inverse square root of sample size.

**Fast route.** Solve $\sigma/\sqrt{n_{\rm new}}=(1/2)\sigma/\sqrt n$, giving $n_{\rm new}=4n$.

**Trap.** Doubling sample size only divides standard error by $\sqrt2$.

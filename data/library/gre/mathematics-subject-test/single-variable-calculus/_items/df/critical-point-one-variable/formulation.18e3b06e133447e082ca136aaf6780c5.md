An interior point $c$ of the domain of a real function $f$ is a critical number if $f'(c)=0$ or $f'(c)$ does not exist. The function itself must be defined at $c$.

A differentiable interior local extremum has derivative zero. Endpoints must be considered separately when studying extrema on a closed interval.

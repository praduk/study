A bounded function $f:[a,b]\to\mathbb R$, $a<b$, is Riemann integrable with integral $I$ iff all tagged sums

$$
\sum_{j=1}^n f(\xi_j)(x_j-x_{j-1}),
\qquad \xi_j\in[x_{j-1},x_j],
$$

tend to the same finite $I$ as the partition’s maximum subinterval length tends to zero. Write $I=\int_a^b f(x)\,dx$.

The sheet’s “signed area” description is the geometric interpretation: portions below the axis contribute negatively.

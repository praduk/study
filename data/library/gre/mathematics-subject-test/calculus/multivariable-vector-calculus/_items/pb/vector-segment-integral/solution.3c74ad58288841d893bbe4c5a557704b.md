**Pattern cue.** Use a path parametrization in the vector line integral.

**Fast route.** With $x=t,y=t$, $0\le t\le1$, the integral becomes $\int_0^1t\,dt=1/2$. Reversing the path changes the sign.

**Trap check.** Using $ds=\sqrt2dt$ would compute a different integral.

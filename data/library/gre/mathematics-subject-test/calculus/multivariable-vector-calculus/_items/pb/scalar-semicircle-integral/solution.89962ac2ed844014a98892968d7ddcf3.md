**Answer.** $2$.

**Pattern cue.** Parametrize and multiply by speed.

**Fast route.** Use $(x,y)=(\cos t,\sin t)$, $0\le t\le\pi$. Speed is $1$, so the integral is $\int_0^\pi\sin t\,dt=2$. Reversing orientation gives the same scalar integral.

**Trap check.** This is not a vector line integral and does not acquire an orientation sign.

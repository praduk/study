Let $f$ be $C^2$ near a critical point $(a,b)$ and set $D=f_{xx}f_{yy}-f_{xy}^2$ there. If $D>0$, the point is a strict local minimum when $f_{xx}>0$ and a strict local maximum when $f_{xx}<0$. If $D<0$, it is a saddle. If $D=0$, the test is inconclusive.

**Pattern.** First verify both first derivatives vanish; a zero determinant does not classify the point.

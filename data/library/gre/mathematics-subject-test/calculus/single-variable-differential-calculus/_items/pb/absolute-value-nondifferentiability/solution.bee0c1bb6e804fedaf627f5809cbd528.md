**Correct choice: (B).**

**Fast route.** Away from the zeros of $x^2-1$, the sign is locally fixed and the function is polynomial. At $x=\pm1$, the inside crosses zero with nonzero derivative $2x$, so the absolute value creates a corner. Hence there are exactly two nondifferentiable points.

A zero inside an absolute value does not always create a corner; for example, $|x^2|=x^2$. The nonzero crossing slope is the decisive check here.

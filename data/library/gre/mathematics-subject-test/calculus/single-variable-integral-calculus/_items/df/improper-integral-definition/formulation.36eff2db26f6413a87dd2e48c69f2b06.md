An infinite endpoint or interior singularity requires a limit. For example,

$$
\int_a^\infty f=\lim_{b\to\infty}\int_a^b f.
$$

If there is a singularity at $c\in(a,b)$, the ordinary improper integral converges only when $\int_a^c f$ and $\int_c^b f$ converge separately. A symmetric principal value is a different notion.

**Pattern.** Unbounded integrands can be integrable; cancellation across a singularity is not a convergence argument.

For finite $G$, the conjugacy class of $x$ has size $[G:C_G(x)]$, where $C_G(x)=\{g:gx=xg\}$. Central elements have singleton classes. Taking one representative from each noncentral class,

$$
|G|=|Z(G)|+\sum_i[G:C_G(x_i)].
$$

Here $Z(G)$ is the center.

**Recognition cue.** Conjugacy is a group action; compute class sizes as indices.

**Boundary check.** A class size is not the order of its representative.

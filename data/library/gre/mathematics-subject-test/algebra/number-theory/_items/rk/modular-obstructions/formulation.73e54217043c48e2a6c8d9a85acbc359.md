If an integer equation has a solution, reducing it modulo any positive integer preserves equality. Therefore an impossible residue pattern proves there is no integer solution. Squares are $0$ or $1$ modulo four, and $0,1,$ or $4$ modulo eight. Passing a residue test is only a necessary condition.

**Recognition cue.** Use parity or square residues before a long integer search.

**Boundary check.** A compatible residue does not prove that an integer solution exists.

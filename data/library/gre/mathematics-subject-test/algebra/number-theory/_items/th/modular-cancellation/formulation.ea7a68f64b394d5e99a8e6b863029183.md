For $n\ge1$, $a\equiv b\pmod n$ means $n\mid a-b$. Congruences permit addition and multiplication. If $ca\equiv cb\pmod n$ and $d=\gcd(c,n)$, then this is equivalent to $a\equiv b\pmod{n/d}$. Cancellation while keeping modulus $n$ is valid for all $a,b$ iff $\gcd(c,n)=1$.

**Recognition cue.** Cancel common factors only together with the necessary modulus change.

**Boundary check.** Ordinary division can erase valid residue classes.

If an integer-coefficient polynomial $a_nx^n+\cdots+a_0$ has root $p/q$ in lowest terms, with $q>0$, then $p\mid a_0$ and $q\mid a_n$. This is a necessary candidate test, not a sufficient one. If $a_0=0$, first factor out $x$.

**Recognition cue.** Test short rational candidates, especially small answer choices.

**Boundary check.** A rational-root test does not detect every real root.

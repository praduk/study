A function $f:D\to Y$ has an inverse on its image iff it is one-to-one. The inverse has domain $f(D)$ and range $D$. To find it, solve $y=f(x)$ for $x$ while retaining the original domain. A composition $g\circ f$ is defined only where $f(x)$ lies in the domain of $g$.

**Recognition cue.** A quadratic inverse requires a branch choice; a composition may add domain restrictions.

**Boundary check.** An inverse function is not the reciprocal $1/f$.

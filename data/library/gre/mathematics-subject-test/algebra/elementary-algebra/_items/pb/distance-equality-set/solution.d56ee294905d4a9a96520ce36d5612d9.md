**Answer: (D).** $x\ge0$

**Pattern cue.** Equality in the scalar triangle inequality.

**Fast route.** For $x\ge0$, both sides equal $x+2$. For $-2\le x<0$, equality would require $x+2=-x+2$, so only zero, already excluded from this interval. For $x<-2$, the two sides differ by four. Thus exactly $x\ge0$.

**Trap check.** Equality needs aligned signs; the inequality itself always holds.

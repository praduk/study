If $P$ has an ordered basis $\mathcal B$ as its columns in standard coordinates, then $v=P[v]_{\mathcal B}$ and $[v]_{\mathcal B}=P^{-1}v$. If $A$ is an operator in standard coordinates, its matrix in $\mathcal B$ is $P^{-1}AP$.

**Recognition cue.** Label the direction of each coordinate map before multiplying.

**Boundary check.** Changing coordinates is a similarity, not arbitrary row reduction.

If $p(A)=0$, replace sufficiently high powers of $A$ using that relation. If $A^2=cI$ with $c\ne0$, then $A^{-1}=A/c$; if $A^2=A$, then $A^k=A$ for every integer $k\ge1$. These follow by substitution and multiplication, not entrywise squaring.

**Recognition cue.** A given identity can eliminate inverses or large powers.

**Boundary check.** For matrices, $A^2$ means matrix multiplication, not squaring each entry.

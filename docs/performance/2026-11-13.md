## Implementation choices

- Combined session, navigation, and selected-entry reads to remove round trips. The client reconstructs canonical entry tags from the folder namespace and loads Git status when the repository dialog opens. An experiment omitting additional navigation defaults saved another 6 KB or so compressed, at the cost of duplicating more schema rules in the browser.
- Kept local MathJax and its extension support. A build-time component combines the enabled extension scripts and their SVG fonts. Explicit extensions continue to load on demand. Fourteen comparison formulas produced identical SVG, covering extension fonts, chemistry, Mathtools, AMS diagrams, Unicode, cancellation, color, and explicitly loaded compatibility packages.
- Chose build-time Brotli for larger text assets with a gzip fallback. This adds about 7 MiB to the shipped bundle. For the dynamic navigation response, gzip level 5 saved about 14 KB compared with level 3 in a local compression experiment. The level-3 CPU saving was about 3 ms. Level 9 saved about 7 KB compared with level 5 and added about 8 ms.
- Reused validated metadata for review, index rebuilds, reordering, and uploads. Entry reads still check for direct file edits. Review still derives the same modes and queue order, and reads only the prompt or answer family in use.
- Retained durable session lookup and revocation while recording activity at most once per minute. A disposable production-host SQLite microbenchmark measured about 1.4 ms for lookup and write versus 0.1–0.15 ms for lookup alone.

## Reproduction

Freeze the baseline and use the same clean Git root for both builds. The API and browser harnesses copy the library to temporary storage before running mutations. The browser harness chooses a theorem with math, references, and a following sibling for repeatable navigation.

```sh
python scripts/benchmark_performance.py --source-root BASELINE --git-root CLEAN --interactive --samples 9 --pdf --output /tmp/api-before.json
python scripts/benchmark_performance.py --source-root UPDATED --git-root CLEAN --interactive --samples 9 --pdf --output /tmp/api-after.json
python scripts/benchmark_browser.py --source-root BASELINE --git-root CLEAN --samples 5 --output /tmp/browser-before.json
python scripts/benchmark_browser.py --source-root UPDATED --git-root CLEAN --samples 5 --output /tmp/browser-after.json
```
